## For developers

The portfolio is a bilingual static site built with Next.js App Router and TypeScript. It uses shared, validated content for the website and the generated PDF CV, and is deployed through GitHub Pages.

### Run locally

```bash
npm install
npm run dev
```

### Verify or build

```bash
npm test
npm run build
```

`npm run build` generates the localized CV PDFs and exports the static site to `out/`.
